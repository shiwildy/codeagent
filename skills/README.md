# Skills pack

A modular skill pack for request-efficient, tool-driven AI coding workflows.

## Included

- duar: batch execution / minimize request overhead
- scout: codebase reconnaissance
- surgical: minimal safe patching
- sentinel: regression protection
- forensic: root-cause debugging
- contract: behavior/interface preservation
- testsmith: validation and test execution
- critic: adversarial final review
- scope: anti-scope-creep
- context: structured project continuity
- handoff: session continuity
- gitguard: final diff discipline

Recommended execution flow:

DUAR → SCOUT → FORENSIC/CONTRACT → SURGICAL → TESTSMITH → SENTINEL → CRITIC → GITGUARD

CONTEXT and HANDOFF provide continuity across sessions.
SCOPE remains active throughout the workflow.
